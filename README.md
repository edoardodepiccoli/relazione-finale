# Relazione finale di stage

Relazione finale di stage di Edoardo De Piccoli, laurea triennale in Informatica, Università di Padova.

Per ora c'è l'indice proposto, [`indice.pdf`](indice.pdf), in attesa di approvazione. Poi la tesi crescerà un capitolo alla volta in [`tesi.pdf`](tesi.pdf). Ogni versione inviata al relatore ha il tag `invio-N`.

Il testo è in Markdown: l'indice in `indice.md`, i capitoli in `capitoli/`. Per ricompilare: `mise install`, poi `mise run indice` per l'indice e `mise run pdf` per la tesi.
